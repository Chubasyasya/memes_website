# 🐸 MemesWebApp

**MemesWebApp** — это простая социальная сеть, где пользователи могут публиковать, просматривать и лайкать мемы. Проект написан на Java и использует PostgreSQL в качестве базы данных.

---

## Функциональность

- Регистрация и вход пользователей
- Загрузка мемов (изображения + описание)
- Лайки и просмотры
- Сохранение мема по папкам
- Лента мемов

---

## Технологии

- **Java / Jakarta EE / Servlets**
- **PostgreSQL**
- **HTML / CSS / JS**
- **Tomcat 10**
- Maven
